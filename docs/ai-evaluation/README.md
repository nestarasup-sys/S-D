# Avaliação criativa de IA externa

Este pacote prepara um teste que o responsável executará em outra conversa. Nenhum serviço ou modelo externo é chamado pelo Studio Dark.

Use somente estes documentos como entrada técnica e criativa:

- [Guia técnico para IA](../GUIA-PARA-IA.md)
- [Direção de roteiro dinâmico](../DIRECAO-ROTEIRO-DINAMICO.md)
- [Desafio criativo](CREATIVE-CHALLENGE.md)
- [Rubrica de avaliação](RUBRIC.md)
- [Importação e análise local](IMPORT-AND-ANALYZE.md)

Quando a IA entregar o arquivo `.production.json`, preserve uma cópia original e importe uma cópia no Studio Dark. Execute a análise visual pelo editor ou pelo worker e revise os quadros indicados. A análise é uma ajuda, não uma aprovação automática.
