# Desafio criativo — documentário tecnológico curto

Crie uma produção original de 15 a 25 segundos, em português do Brasil, sobre como sistemas digitais influenciam uma tarefa cotidiana. Não invente estatísticas nem atribua frases a pessoas reais. Se usar dados, marque-os como demonstrativos ou forneça referências editoriais verificáveis.

Use apenas as capacidades e os IDs listados nos dois guias. Entregue uma receita `studio-dark-production` v3 válida, pronta para importação.

Requisitos de direção:

- Narração pt-BR em frases faláveis, legendas ligadas à narração e pausas para leitura.
- Use pelo menos três recursos premium reais, com slots textuais e paletas personalizadas.
- Inclua um travelling espacial em que um ponto de interesse já existe na cena e entra no enquadramento sem Visual Beat `show`.
- Inclua outra revelação temporal por Visual Beat durante movimento de câmera.
- Varie enquadramento, escala e ritmo. Não repita a mesma entrada em todos os elementos.
- Reserve espaço para legenda, mantenha texto legível e construa uma hierarquia clara em cada shot.
- Use transições somente quando conectarem trechos da narrativa.
- Prefira composições deliberadas a preencher todos os espaços com decoração.

Entregue somente o JSON e uma breve nota com duração, recursos premium usados, referências factuais e intenção de cada movimento. Não use imagens remotas; para o desafio técnico, não é necessário preencher slot de imagem.
